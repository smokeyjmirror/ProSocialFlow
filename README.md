# ProSocialFlow
This app contains features: 
  -generating an image-of-the-day (genAI) and alt text (genAI)
  -generating (genAI) news and information reports for 8 topics (stem, ai-agi-asi, politics, sports, wildlife, vegan-living, streaming, gaming)
The generated content is pushed to Bluesky and Discord (manually) after human review.
This creator of this space is passionate for nature, wellness, fitness, technology. Kindness and ambition lead the way.
